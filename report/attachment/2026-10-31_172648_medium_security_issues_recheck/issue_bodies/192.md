## 概要

ログ保存先の初期化では、書き込めるかを確かめるために、固定名の `.write_test` に `fs::write` で空データを書いてから削除します。同名のファイルがすでにあると中身を消して削除し、Unix で同名の symlink があると、その参照先を空にしてから symlink を削除します。初期化するだけで、ログ root の外にあるファイルまで書き換わる可能性があります。

- [`foundation.rs:300-310`](https://github.com/miminashi/mesh-llm/blob/007d052d8/mesh/crates/mesh-llm-host-runtime/src/logging/foundation.rs#L300-L310): `root.join(".write_test")` に `std::fs::write` で書き、`remove_file` する。既存のファイルや symlink かどうかは見ていない
- [`foundation.rs:59-72`](https://github.com/miminashi/mesh-llm/blob/007d052d8/mesh/crates/mesh-llm-host-runtime/src/logging/foundation.rs#L59-L72): 設定された app state root から初期化する

## 期待する動作

書き込めるかの確認は、`create_new`（`O_EXCL`）で新しく作った一意な名前の一時ファイルで行い、後片付けでは自分が作ったファイルだけを消す。既存の同名ファイル、symlink、その参照先は変更も削除もしない。書き込める root は今までどおり使え、書き込めない root は失敗として扱う。
