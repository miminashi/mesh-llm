## 概要

公開 API の `install_skills` は、`SkillPackage.name` を検査せずに、配置先の Skill root へそのまま join します。絶対 path の名前を渡すと root そのものが置き換わり、`..` を含めると root の外に出るため、選んだ agent の Skill root の外に SKILL.md を書き込めます。名前を検査する関数 `is_valid_skill_name` はありますが、この入口では呼ばれていません。

## 期待する動作

`install_skills` の入口で、name が空でない単一の `Component::Normal` であることを確かめ、絶対 path・`..`・複数の要素を含む名前はファイル操作の前に拒否する。dry-run でも同じエラーを返す。既存の安全な名前と、marker・force・conflict の動作は変えない。
