## 概要

config で `enabled = false` にした plugin でも、外部 CLI コマンド（`mesh-llm <plugin名> ...`）として呼ぶと起動できます。CLI の解決処理は、config 側で無効だと `None` を返した後、installed store を検索し直し、store 側で有効になっていればその実行ファイルを起動します。通常の runtime の解決では、config に同名の entry があれば installed store への fallback を止めており、CLI の経路だけが違う動きをしています。

## 該当箇所（`007d052d8` 時点）

- [`mesh-llm/src/commands/plugin_cli.rs:108-116`](https://github.com/miminashi/mesh-llm/blob/007d052d8/mesh/crates/mesh-llm/src/commands/plugin_cli.rs#L108-L116): `resolve_configured_cli_plugin` が `None` なら、続けて `resolve_installed_cli_plugin` を呼ぶ
- [`plugin_cli.rs:124-126`](https://github.com/miminashi/mesh-llm/blob/007d052d8/mesh/crates/mesh-llm/src/commands/plugin_cli.rs#L124-L126): config で無効な entry は、エラーにせず `bundled_cli_plugin_spec` を返す
- [`host-runtime/src/plugin/config.rs:540-542`](https://github.com/miminashi/mesh-llm/blob/007d052d8/mesh/crates/mesh-llm-host-runtime/src/plugin/config.rs#L540-L542): `bundled_cli_plugin_spec` は常に `Ok(None)` を返す
- [`host-runtime/src/plugin/installed.rs:177-180`](https://github.com/miminashi/mesh-llm/blob/007d052d8/mesh/crates/mesh-llm-host-runtime/src/plugin/installed.rs#L177-L180): runtime の解決では、config にある名前の installed plugin は飛ばしている

## 期待する動作

config で明示的に無効にした名前は、そこで解決をやめ、installed や bundled への fallback に進まない。無効な plugin を CLI から呼んだときは、理由の分かるエラーで失敗する。config に無い、installed で有効な plugin は、今までどおり CLI から使える。
