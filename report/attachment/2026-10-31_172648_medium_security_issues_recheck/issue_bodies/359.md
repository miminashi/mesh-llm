## 概要

bucket sync は、remote の listing から得た file path を、そのまま取得先のローカル root に join して書き込みます。`..` や絶対 path を含む key が listing に入り、filter を通ると、指定したディレクトリの外にディレクトリを作ってファイルを書き込みます。削除のときも同じ path で `remove_file` します。取得先にある既存の symlink を経由して root の外に出ることも防いでいません。

## 期待する動作

remote path を使うすべてのファイル操作の前に、root 内の安全な相対 path（`Component::Normal` だけからなる）であることを確かめ、`..`・絶対 path・root の外を指す既存の symlink は拒否する。正当な nested file と空ファイルの同期は、今までどおりできる。
