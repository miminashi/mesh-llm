## 概要

ファイルを bytes として取得する処理は、サーバが返したサイズ（Content-Length）をそのまま buffer の初期容量に使い、body も上限なしで全部ためます。実体よりはるかに大きなサイズを返す endpoint に当たると、body を読む前に巨大なメモリ確保を要求し、プロセスが落ちる可能性があります。小さな catalog JSON の取得にも同じ経路を使っています。

- [`skippy-model-package/src/bin/queue-unsloth-layer-packages.rs:948-958`](https://github.com/miminashi/mesh-llm/blob/007d052d8/skippy/crates/skippy-model-package/src/bin/queue-unsloth-layer-packages.rs#L948-L958): catalog JSON を `download_file_to_bytes` で取得する

## 期待する動作

初期容量は上限付きの hint として扱い（例: 数 MiB で打ち切る）、用途ごとに最大の取得 byte 数を設定できるようにする。サイズの header が大きいだけでは巨大な確保をしない。上限を超える body ははっきりしたエラーにし、小さな catalog は今までどおり取得できる。
