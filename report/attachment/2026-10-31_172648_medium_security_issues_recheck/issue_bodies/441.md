## 概要

`just mesh-client` と `just release-bundle` の recipe は、引数を `{{ ... }}` で bash のソースに文字列として埋め込んでいます。just は値をテキストとして置換してから shell に渡すため、値に含まれる `$(...)` や `$VAR`、引用符は shell の構文として評価されます。細工した招待 token を `just mesh-client join=...` に貼り付けて実行すると、その人の権限で任意のコマンドが動きます。

## 該当箇所（`007d052d8` 時点）

- [`just/mesh-client.just:7-14`](https://github.com/miminashi/mesh-llm/blob/007d052d8/just/mesh-client.just#L7-L14): `port`・`console`・`join`・`config`・`mesh_bin` を `"{{ join }}"` のように二重引用符の中へ補間する。recipe に `[positional-arguments]` は付いていない
- [`just/release-bundle.just:6`](https://github.com/miminashi/mesh-llm/blob/007d052d8/just/release-bundle.just#L6): Unix 版は `flavor`・`arch`・`version`・`output` を shell の行へ補間する
- [`just/release-bundle.just:10`](https://github.com/miminashi/mesh-llm/blob/007d052d8/just/release-bundle.just#L10): Windows 版も PowerShell の引数へ同じように補間する

## 期待する動作

引数は `[positional-arguments]` と `"$@"`、または export した変数で渡し、shell 側で引用して展開する。空白・引用符・`$`・コマンド置換を含む値も、一つの literal な引数としてそのまま届く。既存の引数の順序と、空の値の扱いは変えない。
