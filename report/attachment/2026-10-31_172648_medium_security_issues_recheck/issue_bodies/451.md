## 概要

CI の `compute-changes` action は、変更されたファイルの一覧を、固定の `EOF` を区切りにした multiline 形式で `GITHUB_OUTPUT` に書きます。変更一覧に `EOF` という名前のファイル（repo root の `EOF`）があると、値がそこで終わり、残りの path が `GITHUB_OUTPUT` の行として解釈されます。PR で `EOF` と `name=value` 形式の名前のファイルを足すと、後続の output を偽造できる可能性があります。

## 該当箇所（`007d052d8` 時点）

- [`.github/actions/compute-changes/derive-outputs.sh:426-429`](https://github.com/miminashi/mesh-llm/blob/007d052d8/.github/actions/compute-changes/derive-outputs.sh#L426-L429): `echo "changed_files<<EOF"` の後に変更一覧を `cat` し、`echo "EOF"` で閉じる
- [`.github/actions/compute-changes/action.yml:82`](https://github.com/miminashi/mesh-llm/blob/007d052d8/.github/actions/compute-changes/action.yml#L82): 変更一覧は `git diff --name-only` の結果そのもの

## 期待する動作

`changed_files` の output が不要なら取り除く。必要なら、内容と衝突しない区切り（毎回ランダムに作る文字列など）を使うか、ファイルで渡す。`EOF` という path と通常の path が混ざっていても、出力の処理が成功し、変更一覧も欠けない。
