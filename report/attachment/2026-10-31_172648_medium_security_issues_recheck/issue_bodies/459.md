## 概要

CI の一部の job で、秘密情報（Anthropic の API key、HF token）を job 全体の `env` に置いているため、認証が不要な step（外部パッケージの install、ソースの準備、後片付けなど）にも渡っています。たとえば、Claude live gate では npm の `install --global` の実行中にも API key が環境変数にあります。
